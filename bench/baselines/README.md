# Baselines

The control group: a bare coding agent with no contract, no verification surface, and no gates,
running the same tasks.

Its purpose is evidence, not embarrassment. If the baseline does *not* produce inflated Sharpe
ratios on trap tasks, then the trap is not realistic and the task needs fixing before any Veil
score from it can be trusted.

Reports land here from Stage 1, covering at least two models.
