# Single-agent loop

This cold example exercises the Stage 3 delivery orchestration without calling a model. It shows how
a brief and ordinary development read become a portable, reviewable promotion candidate rather than
ending as disconnected chat output and workspace files:

```text
brief → durable hypothesis entry → guarded development read
      → artifact package → fresh walk-forward contract
      → C6 chronology → unverified promotion candidate
      → immutable run evidence + append-only Markdown log
```

Run it from the repository root:

```bash
npm run agent-loop:verify
```

The example creates an isolated temporary project, copies the committed CSV, adapter, factor, and
project profile into it, and removes the project after the cold run. Its final JSON is path-free.
No model, network service, credential, performance pricing output, return, metric, gate verdict, or
Experiment is created. The successful Stage 3 result is only a structurally verified promotion
candidate; Stage 4 must still add pricing, costs, statistical gates, and Experiment issuance.

Use the files here as shapes, not as research defaults. In particular, replace the toy pass-through
factor, schedule, cost-model reference, and protocol with declarations appropriate for the real
question.
